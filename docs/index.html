Возможности плеера

Только нужные функции для ежедневного прослушивания музыки

Умная бесконечная волна

Музыкальный поток под ваши предпочтения, который непрерывно подбирает треки по лайкам и дослушиваниям.

Интерактивный граф вкусов

Наглядная 2D-карта ваших предпочтений со связями между артистами и любимыми жанрами.

Офлайн-кэш на диске

Сохраняйте треки на компьютер в 1 клик для прослушивания музыки без интернета.

Быстрый каталог

Мгновенный поиск любых треков, альбомов и авторов в SoundCloud без задержек.

Очередь с историей

Список недавно сыгранных песен с возможностью вернуться к любому треку без сброса текущей волны.

Discord статус

Автоматически отображает играющий трек, автора, обложку и таймлайн в профиле Discord.

Вход в аккаунт в 1 клик

Открытое расширение freakcloud-extension безопасно передает авторизацию из браузера в плеер без ручного ввода токенов.
