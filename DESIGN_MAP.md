# freackcloud — Design Map (Дизайн-система и визуальный манифест)

Документ фиксирует фундаментальные визуальные правила, дизайн-токены и архитектуру интерфейса плеера **freackcloud**, полностью исключая шаблонные решения («полусерые тона с обводкой и скруглением», вложенные карточки, визуальный шум).

---

## 1. Манифест: Отказ от AI-шаблонов

### ❌ Что мы полностью устраняем:
1. **«Полусерые тона» (Murky Zinc Grays)**:
   - Отказ от засилья грязно-серых подложек (`bg-zinc-900`, `bg-zinc-950/80`, `bg-zinc-800`), из-за которых интерфейс выглядит мутным, выстиранным и плоским.
2. **«Рамки вокруг всего» (Border Overuse / Bento Slop)**:
   - Отказ от упаковывания каждого абзаца, иконки и строки в карточки с обводками `border border-zinc-800`. 
   - Разделение пространства строится на **пустом пространстве (whitespace), масштабе шрифта и выравнивании**, а не на заборах из линий.
3. **«Раздутые скругления» (Over-rounding)**:
   - Отказ от пузырей `rounded-2xl`, `rounded-3xl` и небрежных радиусов. Интерфейс плеера должен быть строгим, выверенным и техничным.
4. **«Карточки внутри карточек» (Nested Boxes)**:
   - Контент подается плоско и напрямую, без многослойных «коробочек в коробочках».

### ✦ Наш вектор: Precision Audio & Industrial Minimalism
- **Характер**: Профессиональное аудиооборудование (Braun / Dieter Rams, Teenage Engineering, Ableton, студийные консоли).
- **Контраст**: Глубокий монохром — истинный черный (True OLED Black `#000000`) и чистый белый текст высокой четкости.
- **Акцент**: Чистый белый (`#ffffff`) — бескомпромиссный монохромный студийный контраст без лишних цветных пятен и размытых свечений.

## 2. Цветовая палитра и токены контраста

| Роль | Значение HEX | Назначение |
| :--- | :--- | :--- |
| **Canvas / Background** | `#000000` | Абсолютно черный, глубокий OLED-фон всего приложения. |
| **Surface (Structural)** | `#080808` / `#0d0d0d` | Скрытые плоскости панелей (сайдбар, плеер). Никаких серых пятен. |
| **Surface Hover** | `#141414` | Деликатная подсветка интерактивных строк без рамок. |
| **Ink Primary** | `#ffffff` | 100% контрастный белый для названий треков, заголовков и активных состояний. |
| **Ink Secondary** | `#8e8e93` | Спокойный нейтральный цвет для исполнителей, подсказок и второстепенных меток. |
| **Ink Dimmed / Meta** | `#48484a` | Монохромные индексы, неактивные иконки, нумерация. |
| **Hairline Divider** | `#1a1a1a` (1px) | Волосковые разделители **только** на границах главных модулей (шапка, сайдбар, плеер). |
| **Signal Accent** | `#ffffff` | Чистый белый индикатор (активный трек, акцент переключателей, волновой поиск). |
| **Focus / Active Rule** | `outline: none` | Полный запрет на появление случайных браузерных обводок и рамок при `:active` и `:focus`. |

## 3. Геометрия, радиусы и границы

```
   [ 0px / Строгий угол ]           [ 2px–4px / Микро-радиус ]           [ 9999px / Пилюля (редко) ]
  Обложки треков, таблицы,         Кнопки управления, поля ввода,       Только бейджи статуса
  структурные панели              всплывающие тултипы                  и переключатели режимов
```

1. **Радиусы (Border Radius)**:
   - Обложки альбомов: `rounded-none` (0px) или `rounded-[2px]` — физический вид виниловой пластинки / CD.
   - Строки треков: плоские прямоугольники с микро-паддингом, без внешних рамок.
   - Кнопки: строгие прямоугольные `rounded-[4px]` или `rounded-none`.
   - Модальные окна и Drawer: чистая форма `rounded-lg` (8px) максимум, без гигантских скруглений.
2. **Границы (Borders)**:
   - Контентные карточки **не имеют обводок**.
   - Таблицы отделяются воздухом (margin/padding), а не сеткой из линий.
   - Разделители — только горизонтальные/вертикальные одиночные hairline-линии `1px border-[#181818]`.

## 4. Типографическая сетка (Type Hierarchy)

Иерархия строится через **контраст размера и начертания**, а не раскрашивание текста в случайные оттенки серого:

| Уровень | Размер / Интерлиньяж | Начертание | Шрифт | Применение |
| :--- | :--- | :--- | :--- | :--- |
| **Display Title** | `28px / 34px` | Bold (700), `-0.03em` | Outfit / Sans | Главные заголовки экранов («Добрый вечер», «Медиатека») |
| **Section Title** | `18px / 24px` | SemiBold (600), `-0.02em` | Outfit / Sans | Секции страниц, названия плейлистов |
| **Track Title** | `14px / 20px` | Medium (500), `-0.01em` | Plus Jakarta Sans | Название играющей композиции |
| **Body / Artist** | `13px / 18px` | Regular (400) | Plus Jakarta Sans | Имя артиста, описания, подсказки |
| **Technical Meta** | `11px / 14px` | Medium (500), `+0.04em` | **JetBrains Mono** | Тайминги (`03:42`), проценты (`80%`), битрейт, счетчики |

## 5. Компонентная спецификация

### 1. Боковое меню (Sidebar)
- Чистая черная панель (`#000000`).
- Сверху: минималистичный логотип и текстовый логотип `freackcloud` без декоративных цветных кружков.
- Центр: фирменный **Glider** (3 пункта: Главная, Поиск, Медиатека) с золотистым лучом `#f7e479`.
- Снизу: кнопка «Настройки» и минималистичный блок профиля (аватар + никнейм).

### 2. Шапка (Header)
- Никаких серых рамок вокруг поиска.
- Поисковое поле: плоская минималистичная строка, подсвечиваемая при фокусе тонкой линией снизу либо деликатным фоном `#111111`.
- Справа: лаконичные кнопки окна Windows (свернуть, развернуть, закрыть).

### 3. Главная страница (Home)
- Крупный чистый заголовок без серых плашек под ним.
- Секция рекомендаций / «Моя волна»: динамический графический стрим (волна / аудиоспектр), а не набор одинаковых серых карточек.
- Таблица недавних треков: ровный плоский список с мгновенным откликом.

### 4. Таблица треков (Track Table)
- Формат без рамок: строки отображаются прямо на черном фоне.
- При наведении (hover): строка подсвечивается монохромным `#111111`.
- Кнопки быстрых действий (лайк, добавить в очередь, скачать в кэш) появляются плавно при наведении.
- Тайминг трека — моноширинным шрифтом для идеального вертикального выравнивания.

### 5. Консоль плеера (PlayerBar)
- Монолитная панель внизу (`#000000`), отделенная от контента тончайшей линией `1px #161616`.
- Никаких шильдиков-заглушек («SoundCloud»).
- Точный регулятор громкости с моноширинными процентами (`80%`).
- Кнопка очереди с аккуратным счетчиком, открывающая строгую выдвижную консоль очереди.
